# Job Application Tracker

Deploy-ready React/Vite version of the DPMG Job Application Tracker.

## Run locally

1. Install Node.js 18+
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite.

## Deploy

Use Vercel, Netlify, or another static hosting service. Build command: `npm run build`; output directory: `dist`.

Data is persisted in the browser using localStorage.
